## 🚀 About

DotFit is a backend-powered fitness tracking app with REST API support and Flutter-based mobile/web UI.  
The API is under active development, with Swagger/OpenAPI documentation coming soon.

---

## ⚡ Quick Start & Usage

> **Requirements:**  
> - Python 3.7+  
> - All dependencies listed in `requirements.txt`

**Steps to run locally:**

```bash

# Navigate to the directory with manage.py
cd trainapp
python manage.py migrate
python manage.py runserver 8888
```

⚠️ SQLite is used by default for testing purposes. You can configure your own database.
